CENTRAL DE AJUDA

Como usar o sistema

Um guia rápido para a equipe aprender as principais rotinas sem depender de treinamento técnico.

Primeiros passosO básico para começar
  1. Entre com seu e-mail e senha individual.
  2. Confira o Painel para ver agenda, pendências e valores do dia.
  3. Use o botão Novo agendamento no topo para marcar um atendimento rapidamente.
  4. Use a busca no topo para localizar pacientes e registros sem navegar por várias telas.
AgendaMarcar, editar e acompanhar atendimentos

Para criar um atendimento, clique em Novo agendamento. No campo Paciente, comece a digitar o nome, telefone ou CPF e selecione a pessoa que aparecer na lista.

Use os filtros de status para visualizar rapidamente aguardando, confirmados, concluídos ou cancelados.

PacientesCadastro e pesquisa

Cadastre nome, telefone, CPF, e-mail e informações de cobrança. Depois, pesquise digitando qualquer parte do nome, telefone ou CPF.

Ao criar aplicações, recebimentos ou agendamentos, você não precisa percorrer uma lista enorme: basta começar a digitar o nome do paciente.

FinanceiroRecebimentos e despesas

Em A receber, registre valores pendentes e marque como pago quando receber. Em Despesas, registre as saídas da clínica.

A tela Financeiro calcula automaticamente entradas, despesas, saldo e valores pendentes.

EstoqueEntradas, saídas e alertas

Cadastre cada item com quantidade, estoque mínimo, lote e validade. Use Movimentar para registrar entrada ou saída.

Os filtros ajudam a localizar itens com estoque baixo ou validade próxima.

Usuários e acessosSomente administradores

Administradores podem criar logins individuais para cada pessoa da equipe, bloquear acessos e redefinir senhas.

Nunca compartilhe uma única senha entre toda a equipe; cada pessoa deve usar seu próprio acesso.

Dica

Se alguma tela ficar diferente depois de uma atualização, pressione Ctrl + F5 para carregar a versão mais recente.
